# Phase 1 — Version 1

> Goal: Full-featured system for a single library or small library network.

**Status:** Planned  
**Depends on:** [MVP](./mvp.md) complete

---

## Features Included

### Catalog Enhancements
- [ ] Multi-language book records (Khmer + English fields)
- [ ] Tags and genre categorization
- [ ] Journals, magazines, and serial management
- [ ] Bulk import via CSV / Excel

### Member Enhancements
- [ ] Member card generation with QR code (printable)
- [ ] Membership expiry and renewal workflow
- [ ] Photo upload for members

### Circulation Enhancements
- [ ] Holds / reservation queue
- [ ] Renewal / extension requests
- [ ] Lost book management and fee collection
- [ ] Fine payment recording with receipt generation

### OPAC — Public Catalog
- [ ] Public-facing search portal
- [ ] Advanced search (author, title, subject, year, language)
- [ ] Real-time availability status

### Notifications
- [ ] Telegram Bot: due date reminders
- [ ] Telegram Bot: overdue alerts
- [ ] Telegram Bot: reservation ready alerts
- [ ] Email notifications (secondary)

### Reporting & Analytics
- [ ] Most borrowed books report
- [ ] Overdue report
- [ ] Member activity report
- [ ] Daily / monthly circulation summary
- [ ] Export to Excel / PDF

### Inventory
- [ ] Stock-taking / shelf audit tool
- [ ] Donation recording
- [ ] Damaged / withdrawn book tracking

### Fine & Payment
- [ ] Wing / ABA KHQR payment recording
- [ ] Payment receipt printing (thermal printer)

### Admin
- [ ] Staff role with restricted permissions
- [ ] Audit log

### Cambodia-Specific
- [ ] Khmer calendar date display option
- [ ] Low-bandwidth UI mode
- [ ] Ministry of Culture report format

---

## Out of Scope for V1
- Mobile app
- Multi-branch
- E-book / digital lending
- Inter-library loan
- Recommendation engine
