# Phase 2 — Version 2

> Goal: Scale to provincial networks, mobile users, and digital collections.

**Status:** Planned  
**Depends on:** [Version 1](./v1.md) complete

---

## Features Included

### Multi-Branch Support
- [ ] Branch creation and management
- [ ] Branch-level inventory with central catalog
- [ ] Branch-to-branch book transfer tracking
- [ ] Per-branch reporting

### Digital Resources
- [ ] E-book / PDF upload and hosting
- [ ] Digital lending with access control (in-library vs. remote)
- [ ] External open-access link management

### Mobile App (Android-first)
- [ ] Member self-service: search, reserve, view history
- [ ] Librarian app: scan check-out / check-in
- [ ] Push notifications via Firebase

### Inter-Library Loan
- [ ] Request book from another branch / library
- [ ] Loan tracking between institutions
- [ ] Return coordination

### Procurement
- [ ] Purchase order creation and tracking
- [ ] Supplier management
- [ ] Budget tracking per branch

### Advanced Features
- [ ] Book recommendation engine (based on borrowing history)
- [ ] Reading program / challenge tracking (for school libraries)
- [ ] Parent / guardian account linking for minor members
- [ ] National library catalog API integration (if available)

### SMS Notifications
- [ ] SMS via Cellcard / Smart / Metfone gateway
- [ ] Fallback from Telegram for non-app users

### Compliance & Standards
- [ ] MARC 21 bibliographic record export / import
- [ ] Z39.50 protocol support (optional, for catalog sharing)
- [ ] Full Ministry of Culture statistical reporting

---

## Out of Scope for V2
- Web scraping / auto-cataloging (post-V2 research feature)
- AI-powered cataloging assistant
