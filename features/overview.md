# Complete Feature List

## 1. Catalog Management
- [ ] Add / edit / delete books, journals, magazines, digital resources
- [ ] ISBN / barcode lookup for auto-fill metadata
- [ ] Multi-language support (Khmer + English)
- [ ] Khmer Unicode full-text search
- [ ] Book cover image upload
- [ ] Dewey Decimal / custom classification system
- [ ] Tag and genre categorization

## 2. Member Management
- [ ] Member registration with National ID / student ID
- [ ] Member types: student, teacher, public, researcher
- [ ] Member card generation (printable / QR code)
- [ ] Membership expiry and renewal
- [ ] Photo upload for members
- [ ] Borrowing history per member

## 3. Circulation (Borrowing & Returns)
- [ ] Check-out / check-in via barcode or QR scan
- [ ] Configurable loan periods by member type
- [ ] Automatic due date calculation
- [ ] Overdue tracking with fine calculation (KHR / USD)
- [ ] Renewal / extension requests
- [ ] Holds / reservation queue
- [ ] Lost book management and fee collection

## 4. Digital Resources
- [ ] E-book / PDF hosting and lending
- [ ] Digital resource access control (in-library only vs. remote)
- [ ] External link management (open access resources)

## 5. Search & Discovery (OPAC)
- [ ] Public-facing Online Public Access Catalog
- [ ] Advanced search: author, title, subject, year, language
- [ ] Real-time availability status
- [ ] Branch / location filter (multi-branch)

## 6. Reporting & Analytics
- [ ] Most borrowed books
- [ ] Overdue reports
- [ ] Member activity reports
- [ ] Daily / monthly circulation stats
- [ ] Inventory reports
- [ ] Export to Excel / PDF

## 7. Administration
- [ ] Admin, librarian, staff roles with permissions
- [ ] Audit log of all actions

## 8. Fine & Payment Management
- [ ] Fine rules configuration (per day rate)
- [ ] Payment recording (cash / Wing / ABA / ACLEDA)
- [ ] Receipt generation

## 9. Inventory & Procurement
- [ ] Stock-taking / shelf audit tools
- [ ] Purchase order tracking
- [ ] Donation recording
- [ ] Damaged / withdrawn book tracking

## 10. Notifications
- [ ] Due date reminders via Telegram Bot

- [ ] Reservation ready notification
