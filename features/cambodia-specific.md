# Cambodia-Specific Requirements

## Language
- Khmer (ខ្មែរ) as default UI language
- English toggle for all screens
- Khmer Unicode search and sorting (NiDA standard)
- Bilingual book records (Khmer title + transliteration)

## Date & Calendar
- Khmer calendar (Chhankitek / ចន្ទគតិ) display option
- Gregorian calendar as system default
- Date format: DD/MM/YYYY (Cambodian convention)

## Connectivity
- Offline-first mode — full core operations without internet
- Data sync when connection is restored
- Low-bandwidth UI mode for provincial branches

## Payments
- Currency: KHR (Riel) and USD (both widely used)
- Supported payment channels:
  - Cash
  - Wing Money
  - ABA Pay (KHQR)
  - ACLEDA Bank
  - Pi Pay (optional)

## Messaging & Notifications
- Telegram Bot (primary channel — most used in Cambodia)
- SMS via local gateway (Cellcard / Smart / Metfone)
- Email (secondary)

## Compliance
- Ministry of Culture & Fine Arts reporting format
- National Library of Cambodia catalog standards
- MARC 21 bibliographic format support

## Multi-Branch
- Provincial library branch support
- Centralized catalog, branch-level inventory
- Branch-to-branch book transfer tracking

## Hardware Compatibility
- Barcode scanner (USB / Bluetooth)
- QR code scanner via phone camera
- Thermal receipt printer support
- Low-cost Android tablet compatible
